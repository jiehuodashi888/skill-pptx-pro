# 个人 PPT 技能 v0.2

基于 PPT Master 6.8.0 的独立个人入口。底层生成工具保留原版，用途分类和视觉风格分别配置。

## 使用

安装后可对 Agent 说：

> 使用 personal-ppt，把本地资料做成工作汇报，使用 clean 风格，允许重新设计页面，只使用本地材料，保留可编辑文字和图表。

也可以要求学习分享、增加新用途类别，或从公司旧 PPT 提取风格。分类不是封闭列表：`report`、`learning-sharing`、`general` 只是起点。

## 扩展

在公司内网单独建立私有资料包，包含 `profiles/` 和 `styles/`。新增用途时添加配置文件，无需改底层导出器。具体格式及安装命令见 `references/usage.md`。

一个用途可以选择不同风格；同一公司风格也可用于汇报、分享、复盘等不同用途。公司品牌约束和提取后的模板单独保存，避免把历史业务数据混入新稿。

## 迁移边界

发布包包含技能源码和文件校验清单，不包含 Python、离线依赖、字体或渲染软件。安装工具不会联网安装依赖，也不会覆盖已有技能。依赖和 GLM 模型连接应在目标内网环境单独配置。

默认不使用外网搜索、生图、语音或上传服务；这是 Agent 工作流规则，并不是系统级断网措施。模型连接仍由宿主环境管理。

实际 GLM + OpenCode 环境尚未测试。配置工具验证通过不等于生成效果验收通过，也不代表自动拥有公司风格库。公司材料需要在内网提取、试做样页并确认后再积累。

## 0.2 实际制作与验证

本版本新增依赖分层诊断、PowerPoint 原生逐页渲染、PPTX 结构与渲染哈希检查，以及离线迁移步骤。分类增加“技术方案”和“复盘总结”，继续支持在私有包中自由扩展。

完整命令与边界见 [制作与交付流程](references/production.md)。`doctor` 只检查环境发现，渲染成功也不等于视觉审查通过；最终仍须逐页查看导出的图片。

本次通用样稿使用 `general + clean`，共八页，覆盖中文可编辑文本、基本形状、不同构图和演讲备注。原生数据图表、动画、外部图像、公司模板保持以及内网 GLM/OpenCode 实跑仍需单独验证。源码包不包含 Python 环境、浏览器和公司资料。
